====================================
  初中英语单词早读工具 — 使用说明
====================================

【如何打开】
  方法1：双击 index.html（用 Chrome / Edge 打开效果最好）
  方法2：把整个 english-vocab 文件夹拖到浏览器窗口

【快速上手】
  1. 左侧选择"年级/学期"
  2. 勾选要读的单元（可多选）
  3. 点击"开始早读"按钮

【操作说明】

  按钮：
  ⏮  上一个单词
  ▶  播放 / 暂停
  ⏭  下一个单词

  快捷键：
  空格键 = 播放 / 暂停
  ←     = 上一个单词
  →     = 下一个单词

  语速：拖动滑块，0.5x ~ 1.5x
  重复：每个单词朗读 1 / 2 / 3 遍
  主题：点击 🌓 切换深色/浅色模式

  点击单词列表中的任意单词，可以跳转播放

【如何导入单词（不需要编辑代码文件）】

  方法：使用内置编辑器（推荐）
    1. 选择年级 → 点击"编辑 / 导入单词"
    2. 在弹窗中选择目标单元
    3. 按格式粘贴单词：
       apple | 苹果
       book | 书
       cat | 猫
    4. 点击"保存"

  从 Excel 粘贴：直接将两列复制粘贴到文本框即可（Tab 分隔自动识别）

  数据存储：导入的单词保存在浏览器本地存储中，不会丢失
  如果换电脑，需要在另一台电脑上重新导入

  方法2：直接编辑 data.js 文件
    用记事本打开 data.js
    按模板格式填入单词：
      { en: "apple", zh: "苹果" },
    保存后刷新浏览器页面即可
